# ShineFS 真机测试清单（REAL_DEVICE_TEST）

> 生成：Cycle 09；V2.1 更新至 Cycle 11H / 2026-09-04
> 原因：以下能力依赖**真实磁场传感器硬件行为**，模拟器虚拟传感器无法等效验证
> （已证实：模拟器 9 轴融合不响应方位角注入，仅俯仰/横滚经重力传导）。
> 结论状态：**CONDITIONAL PASS**。V2.1 模拟器飞行模式闭环已通过；物理 Android 真机尚未连接，磁场硬件、跨姿态实测误差和无磁力计降级仍待执行。

> 模拟器记录（2026-09-04）：`emulator-5554` / `Medium_Phone` / API 37.1 运行最新 Debug 包，`airplane_mode_on=1`；该模拟器实际提供虚拟磁力计与旋转向量，罗盘页展示完整状态。它不能替代物理磁场硬件证据。

## 0. 测试环境要求

- 一台具备磁力计的主流 Android 真机（Android 7.0+ / API 24+）
- 安装 `app-debug.apk`（或签名后的 release 包）
- 测试场地：远离大型金属、音箱、磁吸配件、汽车
