# ShineFS 真机测试清单（REAL_DEVICE_TEST）

> 生成：Cycle 09 / 2026-09-03
> 原因：以下能力依赖**真实磁场传感器硬件行为**，模拟器虚拟传感器无法等效验证
> （已证实：模拟器 9 轴融合不响应方位角注入，仅俯仰/横滚经重力传导）。
> 结论状态：⬜ 未验证（待真机执行后回填）。

## 0. 测试环境要求

- 一台具备磁力计的主流 Android 真机（Android 7.0+ / API 24+）
- 安装 `app-debug.apk`（或签名后的 release 包）
- 测试场地：远离大型金属、音箱、磁吸配件、汽车

## 1. 罗盘方向正确性（核心）

| # | 步骤 | 预期 | 状态 |
|---|---|---|---|
| 1.1 | 打开 App → 风水罗盘，手机水平持机缓慢旋转一整圈 | 罗盘盘面平滑跟随旋转；角度 0–360° 连续变化；**359°↔0° 跨界无反向整圈** | ⬜ |
| 1.2 | 正北/正东/正南/正西四个朝向各停 3 秒 | 读数分别接近 0°/90°/180°/270°（±3°）；向山为 子/卯/午/酉 | ⬜ |
| 1.3 | 缓慢转动 vs 快速甩动 | 均无跳变、无卡死；平滑收敛 | ⬜ |
| 1.4 | 竖持（日常指南针姿势） | 方位读数有效（remap 姿态），无"倾斜过大"误报 | ⬜ |
| 1.5 | 平放桌面（传统罗盘姿势） | 出现"倾斜过大，请正对前方竖持手机"提示（姿态基准为竖持，属预期设计） | ⬜ |
