# ShineFS 术数规则（YIJING_RULES）

> 本文件是**术数规则的唯一事实源**：实现必须与本文件一致，修改规则必须先改本文件。
> 规则版本：**rules-v2.0**（Cycle 10A，2026-09-04；v0.1 全量继承并升级）
> 来源登记见 `DOCS/SOURCE_CATALOG.md`；规则↔来源映射见 `DOCS/RULE_MANIFEST.md`。
> 体系分层（V2.0 方案 §1.4）：《周易》经传（A）/ 梅花易数传统（B）/ 罗经传统（C）/ 历法工程（E）严格分列，禁止混写。

## 1. 角度与方位约定

- 方位角 `azimuth ∈ [0°, 360°)`，北 = 0°，顺时针增大（Android 罗盘惯例）。
- 越界/NaN 一律拒绝（fail-fast）；传感器层负责归一化。
- 区间一律**左闭右开** `[lo, hi)`，跨界按 mod 360 处理。

## 2. 二十四山（`mountains24-v1`，C 级）

- 24 山按 15° 等分：`index = floor(((azimuth + 7.5) % 360) / 15)`；山 i 中心角 = `i × 15°`，
  覆盖 `[i×15° − 7.5°, i×15° + 7.5°)`（mod 360）。
- 顺序（index 0→23）：子 癸 丑 艮 寅 甲 / 卯 乙 辰 巽 巳 丙 / 午 丁 未 坤 申 庚 / 酉 辛 戌 乾 亥 壬。
- 中心角：子0 癸15 丑30 艮45 寅60 甲75 / 卯90 乙105 辰120 巽135 巳150 丙165 / 午180 丁195 未210 坤225 申240 庚255 / 酉270 辛285 戌300 乾315 亥330 壬345。
- 边界锚点：0°→子，7.49°→子，7.5°→癸，352.49°→壬，352.5°→子，359.99°→子。
- 禁止把"山"直接换成数字参与梅花起卦（V2.0 方案 §2.4）。

## 4. 六十四卦（`hexagram-structure-v1`，A 级）

- 编码：下卦（内）三爻 + 上卦（外）三爻，六爻自下而上，阳=1 阴=0。
- 通行本 King Wen 序 1..64；卦符 Unicode `U+4DC0 + 卦序 − 1`；8×8 上下卦全覆盖。

## 5. 动爻与变卦（`changing-line-v1`，A 级）

- 动爻 1..6：1=初爻（最下）…6=上爻（最上）。
- 变卦 = 仅翻动爻一爻，重新拆上下卦映射；翻两次回本卦；384（64×6）全量测试固化。

## 6. 起卦公式（V2 正式定义）

### 6.0 余数归一（`normalize-remainder-v1`，B 级）

```kotlin
fun normalize8(n: Int): Int = ((n - 1) % 8) + 1   // 余 0 取 8（坤）
fun normalize6(n: Int): Int = ((n - 1) % 6) + 1   // 余 0 取 6（上爻）
```

依据：《梅花易数》"八数除之即见卦"惯例余数 1–8 直取（满 8 为坤、余 0 亦为坤）；
六爻同理余 0 作 6。金标准古例数值全部按此复算通过（见 §11）。

### 6.1 模式 A：梅花年月日时（`meihua-time-v1`，B 级）

输入：年支数、农历月数、农历日数、时辰数。

- 年支数：子1 丑2 寅3 卯4 辰5 巳6 午7 未8 申9 酉10 戌11 亥12。
- 年界：**农历正月初一**（观梅占古例"辰年十二月十七日"反推：十二月未跨年；TD-V2-03 立春界不启用）。
- 时辰数：见 §9（禁止 `hourOfDay` 直接入式）。

```text
base      = 年支数 + 农历月数 + 农历日数
上卦先天数 = normalize8(base)
下卦先天数 = normalize8(base + 时辰数)
动爻      = normalize6(base + 时辰数)
```

### 6.2 模式 B：梅花后天端法（`meihua-postheaven-v1`，B 级）

```text
物象 → 上卦（先天数，仅出自 meihua-classimage-v1 类象表）
方位 → 下卦（方位所属后天八卦的先天数）
动爻 = normalize6(物象卦先天数 + 方位卦先天数 + 时辰数)
```

### 6.3 模式 C：时间卦 + 罗盘方应（时空合参）

时间起卦（§6.1）产出本卦/互卦/体用/动爻/变卦；罗盘产出二十四山/后天卦/坐向/方应。
**空间数据不修改时间卦**（V2.0 方案 §10）。大衍筮法与数字起卦冻结（TD-V2-01/02）。

## 7. 互卦（`nuclear-hexagram-v1`，B 级）

- 默认策略 `STANDARD_234_345`：下互 = 原卦第 2、3、4 爻；上互 = 原卦第 3、4、5 爻；64 卦全覆盖（含乾坤）。
- `LEGACY_QIAN_KUN_NO_NUCLEAR`（乾坤无互旧说）为登记策略，未启用。

## 8. 体用与五行（B 级）

### 8.1 体用（`tiyong-v1`）

动爻 1–3 → 下卦为用、上卦为体；动爻 4–6 → 上卦为用、下卦为体。

### 8.2 八卦五行（`trigram-element-v1`）

乾兑金、震巽木、坎水、离火、坤艮土。

### 8.3 五行生克（`element-relation-v1`）

相生：金→水→木→火→土→金；相克：金→木→土→水→火→金。
关系枚举仅判事实：TI_GENERATES_YONG / YONG_GENERATES_TI / TI_CONTROLS_YONG / YONG_CONTROLS_TI / SAME。核心不断绝对吉凶。

### 8.4 时令旺衰（`seasonal-qi-v1`）

春（立春–立夏前）木当令、夏火、秋金、冬水；辰戌丑未月土旺。
依据节气月令（非农历月数）；农历月数只入起卦，两者不得混用（V2.0 方案 §16）。
仅呈现当令五行事实层（TD-V2-05 细目不做）。

### 9.2 农历（`calendar-table-v1`）

内置 1900–2100 历表（版本化 + checksum）；年月日/闰月/月大小由表确定；
锚点 + android.icu.util.ChineseCalendar 抽样交叉核验（业务层不依赖 ICU，方案 §5.2）。

### 9.3 干支（`ganzhi-day-v1` / `ganzhi-year-v1`）

- 日干支：JDN 锚点取模 60（锚点：1900-01-01=甲戌日、1949-10-01=甲子日，双锚互验）。
- 年干支：随农历年（正月初一）轮转。

### 9.4 日界与闰月政策

- `DayBoundaryPolicy.CIVIL_MIDNIGHT`（默认）/ `ZI_HOUR_START_23`（高级，切换须重算并记录规则版本）。
- `LeapMonthPolicy.SAME_MONTH_NUMBER`：闰六月取月数 6（显式工程政策，非梅花原文）。

### 9.5 节气（`solar-term-meeus-v1`）

太阳视黄经 15° 倍数瞬时（Meeus 算法）；进 `YijingTimeContext` 但**不入起卦公式**；
用于时令旺衰与展示；与农历月数分字段（V2.0 方案 §5.5）。

## 10. 原典数据治理（A 级）

- 底本系统：通行本（王弼注/孔颖达疏《周易正义》→ 阮元《十三经注疏》所承，S-A01）。
- 双电子源交叉核验（S-AE1 ctext.org / S-AE2 维基文库）；异文记录于数据校勘注记。
- 数据字段：`sourceId / edition / verified / checksum`；`verified=false` 不得显示"已核定原典"（V2.0 方案 §18）。
- Room 只存用户卦例；原典为版本化静态数据（方案 §17）。

## 12. 禁止自由生成（V2.0 方案 §23）

Random / LLM / 概率生成 / 毫秒取模 / UUID 取数 / 随机吉凶 / 随机文案——正式产品全链路禁止。
相同输入 + 相同规则版本 + 相同历法政策 → 完全相同的演算结果与解释。
