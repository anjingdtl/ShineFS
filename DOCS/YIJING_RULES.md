# ShineFS 术数规则（YIJING_RULES）

> 本文件是**术数规则的唯一事实源**：实现必须与本文件一致，修改规则必须先改本文件。
> 规则版本：**rules-v0.1**（Cycle 01，2026-09-03）
> 数据核定状态：结构性规则已由自动化测试固化；**六十四卦卦名/卦序仍待人工复核**（见 §7）。

## 1. 角度与方位约定

- 方位角 `azimuth ∈ [0°, 360°)`，北 = 0°，顺时针增大（Android 罗盘惯例）。
- 越界/NaN 一律拒绝（fail-fast），不做静默取模；传感器层负责归一化（Cycle 02）。
- 区间一律**左闭右开** `[lo, hi)`，跨界按 mod 360 处理。

## 4. 六十四卦（rules-v0.1）

- 编码：**下卦（内卦）三爻 + 上卦（外卦）三爻**，六爻自下而上，阳爻=1、阴爻=0。
- 卦序：通行本 King Wen 序 1..64；卦符为 Unicode `U+4DC0 + 卦序 − 1`。
- 查询：`(下卦, 上卦)` 二元组唯一确定一卦，8×8 全覆盖。
- 结构数据见 `core/yijing/.../data/Hexagrams.kt`（**待人工复核**，见 §7）。

## 5. 动爻与变卦（rules-v0.1）

来源：产品方案 §4.3。

- 动爻编号 1..6：1=初爻（最下）……6=上爻（最上）。
- 变卦 = 仅翻转动爻一爻（阳⇄阴），其余五爻不变，再按六爻重新拆上下卦映射。
- 同一爻翻转两次必回本卦（测试固化）。
- 已验算方案 §10.1 示例：既济（离下坎上）三爻动 → 屯（震下坎上）✓
