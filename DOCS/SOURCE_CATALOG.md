# ShineFS 文献与数据来源总目（SOURCE_CATALOG）

> 版本：catalog-v2.0（Cycle 10A，2026-09-04）
> 本文件是 V2.0 全部正式规则与数据的**来源登记簿**：任何进入正式代码的术数规则/原典文本/历法数据，
> 必须先在本目录登记来源并获得等级评定；未登记来源的内容不得进入生产链（V2.0 方案 §2/§19/§33-10A）。
> 与 `DOCS/RULE_MANIFEST.md`（规则→来源映射）配套使用。

## 1. 来源分级标准（V2.0 方案 §2）

| 等级 | 定义 | 用途边界 |
|---|---|---|
| A 级 | 《周易》经传正典及其权威注疏系统 | 64卦、卦辞、384爻辞、用九用六、彖、象、八卦象义 |
| B 级 | 宋代象数传统（先天数）与《梅花易数》传统 | 起卦、互卦、体用、五行生克、旺衰、方应 |
| C 级 | 罗经 / 地理术数传统 | 二十四山、坐向、罗盘显示 |
| E 级 | 工程数据与天文历算文献（非术数文本） | 农历历表、干支纪日、节气算法、时辰划分 |

规则：A 级不与 B/C 级混写；B/C 级成果表述必须带体系名（"梅花易数传统""罗经传统"），
禁止写成"《周易》原文规定"（V2.0 方案 §1.4）。

## 6. 已裁定的关键口径（摘要，详见 RULE_MANIFEST 与 YIJING_RULES V2）

1. 余数归一：`normalize8(n)=((n-1)%8)+1`、`normalize6(n)=((n-1)%6)+1`（余0→8/6）——与古例数值自洽（观梅占 34→兑2、43→初爻1 等均按此复算通过）。
2. 年界：农历正月初一换年支（观梅占反推；立春换年为待决策 TD-V2-03，未启用）。
3. 日界：默认民用午夜 `CIVIL_MIDNIGHT`；23:00 换日 `ZI_HOUR_START_23` 为高级策略（方案 §5.4）。
4. 闰月：`SAME_MONTH_NUMBER`（闰六月取6）——显式工程政策（方案 §5.3）。
5. 互卦：默认 `STANDARD_234_345`（乾坤有互）；"乾坤无互"旧说为策略项 `LEGACY_QIAN_KUN_NO_NUCLEAR`，未启用（方案 §13）。
6. 时辰界：左闭右开整点划分（23:00 起为子），见 YIJING_RULES V2 §时辰。
