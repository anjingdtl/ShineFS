# ShineFS V2.0 产品定义（PRODUCT_V2）

> 版本：product-v2.0（Cycle 10A）
> 上游：`DOCS/ShineFS_V2.0_完全离线周易时空演算_完整建设方案.md`

## 1. 一句话定义

ShineFS 是一款**完全离线运行**的周易时空演算工具：以《周易》经传为卦爻正典，
以梅花易数传统为确定性起卦方法，以中国传统历法提供年月日时数据，
以手机电子罗盘提供空间方位与方应数据，并由本地规则引擎完成
本卦、互卦、体用、动爻、变卦及白话释义（V2.0 方案 §0）。

## 2. 红线

100% 离线 · 0 AI · 0 网络 · 0 生产 Fixture · 0 随机演算。
正式 Manifest 不申请 INTERNET / ACCESS_NETWORK_STATE。
相同输入 + 相同规则版本 → 完全相同结果。

## 3. 用户主流程（方案 §38）

打开 App → 显示当前传统历法/时辰 → 时空起卦 →（可选）罗盘定盘锁定空间 →
选择起卦体系 → 本地正式起卦 → 显示 CalculationTrace → 本卦/互卦/体用/动爻/变卦 →
五行/时令/空间方应 → 周易原典 → 本地白话释义 → 保存 → 随时离线复算。

## 4. 结果页固定九段（方案 §24）

一、时空数据；二、起卦过程；三、卦象结果；四、周易原典；五、互卦与体用；
六、五行与时令；七、方位与方应；八、本地白话释义；九、规则来源与版本。
必须显式显示：起卦体系、经典体系、空间体系、历法、日界、北向、规则版本、原典版本。

## 5. 页面清单（方案 §31）

首页：时空起卦 / 风水罗盘 / 传统时间起卦 / 宅居测局 / 卦例记录 / 规则与典籍。
设置：默认起卦体系、日界、闰月策略、互卦策略、北向策略、显示层级。
"规则与典籍"可查看规则版本、原典版本、来源、历法策略与北向策略。

## 6. 风格

玄黑、墨色、古铜金、暗金、朱砂、青玉、象牙白的传统数术风格；
罗盘页含"时间盘"（农历、年支、时辰、节气）；时空并列显示
（时：丙午年 七月廿三 巳时 ／ 空：182.4° · 午山 · 离宫 · 坐子向午）。
UI 优先级低于演算核心（方案 §39）。
